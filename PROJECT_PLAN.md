# Smart EV Charging & Facility Energy Management System

This repository contains my Electrical Engineering portfolio project built using an Arduino UNO R4 WiFi.

The goal is to simulate a smart home energy management system that integrates:

- EV charging
- Solar generation
- Facility battery storage
- Grid power
- Wi-Fi monitoring

Updated module plan:

✅ Module 1 — Analog Input Fundamentals
Potentiometer, ADC, Serial Monitor 

✅ Module 2 — OLED Display Integration
I²C, SSD1306, display buffering

✅ Module 3 — Solar Generation Simulator
Map ADC readings to simulated solar power

✅ Module 4 — Battery Energy Storage System
Battery state of charge, charge/discharge logic, millis() timing

✅ Module 5 — Facility Load Management
Residential or commercial building load, excess/deficit power

✅ Module 6 — EV Charging Controller
EV connection, charging power, EV state of charge, pause/start logic

🟡 Module 7 — Energy Allocation Algorithm
Prioritize facility load, reserve battery, EV charging, battery top-up, grid export

Module 8 — Grid and Demand Management
Grid import/export, peak-demand limits, demand response

Module 9 — Wi-Fi Web Dashboard
Live monitoring and browser controls

Module 10 — Hardware Interface
Buttons, RGB status LED, relay, temperature/fault simulation

Module 11 — Final Integration and Testing
Combine all subsystems, test operating scenarios, improve code organization

Module 12 — PCB and Portfolio Documentation
KiCad design, diagrams, GitHub, results, demo video, resume bullets
